📘 Sistema Documental Inteligente (SDI)

Documento Maestro (Borrador)

Versión Arquitectónica 0.1
Estado: Proyecto Piloto

Visión

Construir una plataforma documental privada, escalable y segura, donde Linux es la fuente de verdad y la base de datos funciona como un índice documental inteligente. El objetivo final es disponer de un sistema completamente documentado, reproducible y publicado como software libre.

Filosofía del Proyecto

  • Linux es la fuente de verdad.
  • MySQL funciona únicamente como índice documental.
  • La IA nunca modifica directamente el filesystem.
  • El sistema debe ser reproducible.
  • La simplicidad tiene prioridad sobre la complejidad.
  • Todo cambio importante debe quedar documentado.

Decisiones Arquitectónicas

  • ✔ Syncthing queda como infraestructura.
  • ✔ Flutter será el cliente oficial.
  • ✔ Linux es la fuente de verdad.
  • ✔ El Full Scan es idempotente.
  • ✔ SHA256 únicamente cuando el sistema modifica archivos.
  • ✔ UUID v7 como identidad pública.
  • ✔ Versionado únicamente para archivos de texto.
  • ✔ Filesystem UI totalmente en modo lectura.
  • ✔ La IA actuará como asistente documental.
